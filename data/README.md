# Data

This folder contains the student well-being dataset used in the SQL analysis.

## File

`students.csv`

The dataset contains student-level information on demographic characteristics, academic status, language proficiency, social support, and well-being measures.

Key variables used in the analysis include:

- `inter_dom` — international or domestic student status
- `region` — student region of origin
- `gender` — gender
- `academic` — academic level
- `stay` — length of stay
- `japanese_cate` — Japanese language proficiency category
- `english_cate` — English language proficiency category
- `todep` — depression score
- `tosc` — social connectedness score
- `toas` — acculturative stress score
